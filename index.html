Questions

What does an AI integration engineer do?

I connect the systems a business already runs on through APIs, webhooks and middleware, and I build AI-powered workflows on top of them. The work spans backend connectors, enterprise API design, data transformation and LLM-based automation.

Which platforms do you work with?

Appmixer, MuleSoft (Anypoint Platform, DataWeave and CloudHub), Integry and Zapier, plus custom code in Node.js, TypeScript, Python and Java when a platform is not the right fit.

What AI work have you done?

At Appmixer I integrated LLM APIs into automation workflows, built integrations with OpenAI, Pinecone and Perplexity, and developed and supported the MCP-based architecture behind the AI Connector Builder. Agentic and AI-assisted development raised connector development velocity by approximately 50%.

How do you handle production problems?

I investigate API errors, authentication failures, webhook issues, rate limits and data inconsistencies, then fix the cause and feed the lesson back into reusable patterns, documentation and tests such as MUnit suites.

Which APIs and authentication methods do you use?

REST, SOAP and webhooks, described with OpenAPI, Swagger or RAML, and secured with OAuth 2.0, OIDC, JWT or API keys. For APIs without webhooks I build polling-based triggers.

Have you led a team?

Yes. At Integry I led six integration engineers, overseeing sprint planning, estimation and releases. At Motive I mentored junior engineers and now guide integration engineers through complex API, authentication and reliability issues.
